# Experiment 4: Develop a Simple Application Using Apex Programming Language on Salesforce

## Aim

To develop a simple custom application using the Apex programming language on the Salesforce cloud platform.

---

## Objectives

* To understand how a Salesforce Developer Org functions.
* To open and use the Salesforce Developer Console.
* To create a custom Apex class and write static methods.
* To compile and save the Apex class.
* To execute the Apex code using the Anonymous Execution window.
* To inspect execution output using Debug Logs.

---

## Software / Platform Used

* **Platform:** Salesforce Cloud Platform
* **Environment:** Salesforce Developer Edition Org
* **Tool:** Salesforce Developer Console
* **Programming Language:** Apex

---

## Procedure

### Step 1: Sign Up and Log In to Salesforce Developer Org

1. Open a web browser and navigate to the Salesforce Developer signup page.
2. Fill in the registration form details such as Name, Email, Role, Company, and Username.
3. Click **Sign me up**.
4. Check the registered email account for the verification message.
5. Click **Verify Account** and set the Salesforce account password.
6. Log in to the Salesforce Developer Org.

---

### Step 2: Open the Developer Console

1. Log in to the Salesforce Developer Org.
2. From the top-right corner of the Salesforce dashboard, click the **Setup Gear Icon** ⚙️.
3. Select **Developer Console** from the dropdown menu.
4. The Salesforce Developer Console opens in a new window.

---

### Step 3: Create a New Apex Class

1. In the Developer Console top menu bar, select:

   **File → New → Apex Class**

2. In the prompt box, enter the class name:

```text
HelloWorldApp
```

3. Click **OK**.

A new Apex class is created with a basic class structure.

---

### Step 4: Write the Apex Code

The basic Apex class structure is generated automatically:

```apex
public class HelloWorldApp {

}
```

Add the `sayHello()` method inside the class:

```apex
public class HelloWorldApp {
    public static void sayHello() {
        System.debug('WELCOME TO APEX PROGRAMMING');
    }
}
```

### Code Breakdown

* **`public class HelloWorldApp`**: Declares a public Apex class named `HelloWorldApp`.
* **`public static void sayHello()`**: Declares a public static method named `sayHello()`. Since the method is static, it can be called directly using the class name without creating an object.
* **`System.debug()`**: Writes the specified message to the Salesforce execution log.

Save the Apex class by selecting:

**File → Save**

Alternatively, press:

```text
Ctrl + S
```

---

### Step 5: Execute the Apex Code Anonymously

1. In the Developer Console menu, select:

   **Debug → Open Execute Anonymous Window**

2. Alternatively, use the keyboard shortcut:

```text
Ctrl + E
```

3. In the **Enter Apex Code** window, enter:

```apex
HelloWorldApp.sayHello();
```

4. Ensure that the **Open Log** checkbox at the bottom-left is selected.
5. Click **Execute**.

The `sayHello()` method is executed anonymously by Salesforce.

---

### Step 6: View the Execution Output

1. After execution completes, the **Execution Log** window opens.
2. At the bottom of the log viewer, select the **Debug Only** filter.
3. The debug output displays the message generated by the `System.debug()` statement.

The expected output is:

```text
|USER_DEBUG|[3]|DEBUG|WELCOME TO APEX PROGRAMMING
```

This confirms that the Apex method executed successfully.

---

## Apex Program

The complete Apex program used in this experiment is:

```apex
public class HelloWorldApp {
    public static void sayHello() {
        System.debug('WELCOME TO APEX PROGRAMMING');
    }
}
```

The method can be executed using:

```apex
HelloWorldApp.sayHello();
```

---

## Result

A custom Apex class named `HelloWorldApp` was successfully created, compiled, and saved inside the Salesforce Developer Org.

The `sayHello()` method was executed anonymously using the Salesforce Developer Console, and the debug message **"WELCOME TO APEX PROGRAMMING"** was successfully displayed in the execution log.

---

## Conclusion

This experiment demonstrated the creation, compilation, and execution of a custom Apex program on the Salesforce cloud platform using the Salesforce Developer Console.

The experiment also demonstrated the use of static methods, anonymous Apex execution, and debug logs for viewing program output.
